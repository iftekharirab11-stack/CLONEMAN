## 💾 STORAGE DETAILS

### **Where Your Chat History is Saved**

```bash
# Main location:
~/.local/share/cloneman/chat_history.json

# Full path:
/home/YOUR_USERNAME/.local/share/cloneman/chat_history.json

# View it:
cat ~/.local/share/cloneman/chat_history.json | jq

# Backup it:
cp ~/.local/share/cloneman/chat_history.json backup.json
```

### **How It Works**

1. You type a message
2. Browser saves locally (instant)
3. Message syncs to server file (auto, 30 sec)
4. Both backups protect your data
5. You can export anytime
6. Survives browser clear

## ⚠️ COMMON ISSUES & FIXES

### **Issue: "Port 5000 already in use"**
**Fix**: The launcher will detect and ask to kill. Or:
```bash
pkill -f "python.*app.py"
```

### **Issue: "API key not working"**
**Fix**: Make sure:
1. .env file exists in project folder
2. Key starts with: `sk-or-v1-`
3. No extra spaces
4. Restart app after editing

### **Issue: "Can't find app in menu"**
**Fix**: Run installer again:
```bash
chmod +x install-app.sh && ./install-app.sh
```

### **Issue: "Chat history not saving"**
**Fix**: Check directory:
```bash
mkdir -p ~/.local/share/cloneman
chmod 755 ~/.local/share/cloneman
```
